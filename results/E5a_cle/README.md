## 판정
- 두 모델 모두 의미 있는 개선 없음 (짝 비교 동률, RN50 B0+SQ는 유의하게 나빠짐). 최종 구성은 그대로.
- RN50: 민감한 stem·L1.0은 잔차 덧셈·downsample 경로라 conv 사이 균형이 닿지 않는다. 가중치가 이미 채널별이라 CLE 본래 이득도 작다.
- SigLIP2: 남은 손실은 fc2 입력(GELU 뒤) 이상치. GELU는 배율을 옮길 수 없어 SQ가 못 고친다 → 블록 5·9 fc2 FP32가 이미 핵심. (팀의 회전·레지스터 캐시가 이 문제를 다른 축으로 푼 것)
- cos만 오르고 top-1은 그대로: cos 단독 지표의 한계 (docs/실험_유의사항.md 1-6)
