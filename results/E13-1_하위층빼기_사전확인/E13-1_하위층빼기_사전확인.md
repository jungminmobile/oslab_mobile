# E13-1 학습 없이 하위층 빼기 — 사전 확인 (FP32) 실험계획서

- 작성: 2026-10-23, 정민 (계획: Claude 세션 A / 실행: 별도 채팅방)
- 출처: 프로젝트 문서 24 SigLIP2 적용안 2순위 (ViT 깊이 가지치기, arXiv 2610.15005, 2026-10)
- 상태: **실행 완료 (2026-10-23) — 중단**. 판정 규칙은 계획 그대로 적용
- 폴더: `results/E13-1_하위층빼기_사전확인/` (계획서 = 이 파일, 결과 = `results/` 하위)

## 1. 목적
제출 모델 **B/32**에서 attention·MLP 하위층(sublayer) 일부를 학습 없이 건너뛰어도 정확도가 거의 유지되는지 **FP32에서만 싸게** 확인한다.
- 이 실험은 **진행 여부를 정하는 관문**이다. 양자화·지연·메모리 측정·test는 하지 않는다 (통과 시 E13-2로 따로 계획).
- 왜 이 기법인가: 연산과 가중치를 실제로 없애므로 예선(ORT)의 **지연·메모리·크기를 함께** 줄이고, 같은 그래프를 본선(Hailo)에도 그대로 쓸 수 있다(컨텍스트 감소 기대).

## 2. 배경과 가설
- B/32 = `hf-hub:timm/ViT-B-32-SigLIP2-256`, 입력 256, 토큰 **8×8 = 64**, 블록 12개(블록마다 attention 1 + MLP 1 = 하위층 24개). FP32 dev 고화질 평균 **89.96%** (G8 b32 README).
- 블록 하나: `x = x + Attn(LN1(x))`, `x = x + MLP(LN2(x))`. 하위층을 빼면 해당 줄만 건너뛴다(잔차는 그대로 흐름).
- 연산 몫(추정): MLP 하위층 하나 ≈ 블록 연산의 약 2/3 → 전체의 약 5.5%. attention 하위층 하나 ≈ 약 2.8%. MLP 하나의 가중치 ≈ 2×768×3072 = 4.7 M개(INT8 약 4.5 MB).
- 가설: 출력에 거의 영향이 없는 하위층이 1~3개 있다. 단, SigLIP 계열은 다른 CLIP보다 중복이 적다는 보고(arXiv 2509.21173)가 있어 **없을 수도 있다**.

## 3. 후보에서 빼는 하위층 (사전 고정)
| 하위층 | 이유 |
|---|---|
| MLP 5, MLP 9 | B/32 M2 통일 규칙 `UNIFIED["b32"] = K/V (15@6, 7@10), u_c 시작 (5, 9)` (`s2_g6.py`). sink 토큰에 거대 값을 쓰는 쪽과 M2 대체 지점에 걸림 |
| Attention 6, Attention 10 | M2 K/V 상수 대체가 시작되는 블록 |
| 블록 0 (Attention 0, MLP 0) | G8 4절 "B/32 블록 0 보호" 기록 (블록 0 민감) |

→ 후보 **18개** (attention 1~5·7~9·11, MLP 1~4·6~8·10·11).

## 5. 판정 규칙 (사전 등록)
| 판정 | 조건 |
|---|---|
| **통과 (E13-2로 진행)** | 어떤 P_k (k = 1~3)가 dev 전체 고화질 FP32 대비 **Δ ≥ −0.2·k %p** (점추정) **그리고 95% CI 하한 ≥ −0.5·k %p**, **그리고** 줄어드는 연산 몫(2절 추정)이 **≥ 5%** |
| 여러 개 통과 | 줄어드는 연산 몫이 가장 큰 P_k. 같으면 Δ가 작은 쪽 |
| **중단** | 통과한 P_k가 없음 → "SigLIP2 B/32는 학습 없는 하위층 제거 여지 없음"으로 기록하고 끝 |

- 연산 몫 ≥ 5% 조건: MLP 1개 또는 attention 2개 이상을 빼야 의미 있는 지연 감소(추정)가 나온다.
- CIFAR A는 판정에 쓰지 않고 기록만 한다 (팀 규칙 D-017과 같음).
- 이 실험 결과로 제출 모델을 바꾸지 않는다. 통과해도 **E13-2(M2 재구성 → O-AB 양자화 → 정확도·지연·메모리 → test)**를 따로 계획·승인한 뒤 진행한다.

## 10. 결과
**결정: 중단** — SigLIP2 B/32는 학습 없는 하위층 제거 여지 없음. 자세한 표는 `REPORT.md`.
- G0 통과: FP32 dev 전체 고화질 89.96 (6종 모두 G8 B2와 같음)
- 하나씩 빼기 18개 모두 고화질 Δ ≤ −10.3%p (가장 덜 나쁜 것 attn9 −10.3, mlp11 −11.0). 관문 −0.2%p와 거리가 멂
- 누적 P1 attn9 −10.3 / P2 +attn8 −74.6 / P3 +mlp6 −75.4 → 모두 스크리닝 탈락, dev 전체 관문 측정 없음
- 비가법성 큼 (attn9+attn8: 단순 합 −26.8 → 실제 −74.6)
