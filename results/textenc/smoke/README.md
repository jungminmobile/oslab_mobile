# 텍스트 인코더 INT8 스모크 — SigLIP2-B/16 (2026-10-16)

**결론 (판단 기준에 따라): 진행 가치 있음.**
- **D(토큰 임베딩 표만 INT8)** 는 세 조건을 모두 만족한다. 클래스 cos 최소 0.9994, Δtop-1 +0.15%p [−0.20, +0.51], 크기 1077 → 516 MiB(−52.1%).
- **C-u8+D(블록 0 c_proj 하나만 FP32 + 나머지 MatMul·Gemm U8 + 임베딩 INT8)** 는 cos 평균 0.996으로 기준을 넘지만 최소는 0.985로 0.99에 못 미친다. Δtop-1 −0.25%p [−0.71, +0.20], 크기 279 MiB(−74.1%), x86 지연 −67%.
- 판단 기준이 cos를 최소로 볼지 평균으로 볼지 정하지 않았으므로 둘 다 적었다.

> 이 결과는 팀 규칙(PRD R6: 텍스트는 FP32로 클래스 임베딩 1회 계산)을 바꾸지 않는다. 배포 때 텍스트 인코더는 기기에서 돌지 않는다(클래스 임베딩을 미리 계산).
> 따라서 이 결과가 뒷받침하는 것은 "모델 전체도 8비트로 줄일 수 있다"는 보고서 문장까지다. HEF 컴파일은 범위 밖이다.

## 측정 조건

- 코드: 브랜치 `textenc/siglip2-smoke`, 커밋 `221bd50`. 모든 jsonl과 speed json이 `dirty: false`.
- 환경: 클라우드 작업 공간 Intel Xeon @ 2.10GHz, 2코어, AVX512-VNNI·AVX-VNNI, RAM 7 GB, ONNX Runtime 1.25.0, Python 3.13, torch 2.14.0, open_clip 3.3.0
  - **지연은 비공식**이다(2코어 클라우드 CPU). 연구실 데스크탑(Ultra 9 285K)·AGX Orin은 아직 재지 않았다.
- 정확도: ORT 기본 설정(ORT_ENABLE_ALL) 정수 커널만 사용. 이미지 임베딩은 팀 dev 캐시와 같은 FP32 값을 쓰고, 텍스트 분류기만 바꿨다.
  - Pets dev 990장(37클래스), Food dev 985장(101클래스), 둘 다 템플릿 1개. 팀 기록과 장수·FP32 top-1(93.33 / 89.44)이 같다.
  - test 분할은 쓰지 않았다.
- Δtop-1은 같은 사진끼리 짝지은 부트스트랩 1000회 95% 구간(`siglip2/s2_paired_ci.boot_hr`)이다. 기준은 같은 경로의 FP32 ONNX 분류기다.
  - FP32 ONNX 분류기는 팀 캐시 분류기(PyTorch)와 cos 0.999999, top-1이 같다.
- 보정 문장: CLIP ImageNet 템플릿 80개 × ImageNet 클래스(Pets·Food 이름과 겹치는 클래스 제외)에서 시드 0으로 256개(`calib_sentences_s0.txt`). 실제로 쓰인 수 = 256 assert 통과.
- 클래스 cos 외에, 보정에 안 쓴 문장 64개(`holdout_sentences_s1.txt`)의 임베딩 cos도 냈다.

**읽는 법**
- **보호 없이 8비트로 하면 무너진다.** 정적 B는 −17%p, 동적 A도 −7%p다. A가 덜 나쁜 이유는 실행 때마다 범위를 다시 재기 때문이다.
- **블록 0 c_proj 하나만 FP32로 두면 회복된다.** cos 0.89 → 0.9965, Δ −17 → −0.35~−0.56%p. 크기는 6.7 MiB만 늘어난다. 이미지 쪽의 "블록 5·9 fc2만 FP32"와 같은 처방이다.
- **임베딩 표는 행별 INT8로 거의 손실이 없다.** 크기는 임베딩 표에서, 속도는 블록에서 나온다. D는 크기·메모리만 줄이고 속도는 그대로다(표에서 행을 찾아오는 것뿐이라서).
- **x86(VNNI)에서 S8은 FP32보다 느리다**(2스레드 +44~55%). 이번 그래프에서 S8은 MatMul 12개와 Gemm 12개가 정수 커널로 합쳐지지 않고, 양자화·역양자화가 남는다(`quantize_log.jsonl`의 연산 개수). U8은 MatMul 59~60개, Gemm 13개가 모두 정수 커널이다. RN50·이미지 쪽에서 알려진 플랫폼 효과와 같다. ARM에서는 아직 재지 않았다.
- 앞 200장만 본 Δ는 흔들림이 크다. 예를 들어 C-s8+D의 Pets는 앞 200장 −2.0, 전체 −0.81이다. 그래서 dev 전체로 판단했다.
