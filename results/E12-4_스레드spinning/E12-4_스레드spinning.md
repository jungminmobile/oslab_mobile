## 2. 근거 (E12-3, 258V, S = B/32 O-AB + C3)
- 프로파일 없는 1T → 4T: 39.07 → **16.27 ms**, 효율 **0.60** (원본 FP32는 0.78).
- 4T 스레드 효율 < 0.5 묶음이 model_run의 43.0% (오버헤드 보정 후 27.0%): Add·Mul·Sub, Q/DQ, 형태 연산, Softmax, GELU.

- P코어 고정 효과 없음(16.43 → 16.60 ms) → E코어 배정이 아니라 **스레드 풀 동기화 비용**으로 본다.

### 0단계 확인: A0의 실제 spinning 값
- 4T에서 **"미지정" 20장**과 **"명시적으로 1" 20장**을 각각 새 프로세스에서 재서 p50과 장당 CPU ms를 비교한다.
- 같으면(p50 ±3%, CPU ms ±10%) A0 = "1"로 확정. **미지정 쪽이 "0"처럼 동작하면**(CPU ms가 "1"보다 뚜렷이 작음) A1의 의미가 뒤집히므로 **멈추고 정민에게 보고**한다.

### 관문 G1 (출력 동일성)
- **대조군 먼저**: 스레드 수마다 **A0 vs A0**(같은 스레드 수로 세션을 2번 만들어 비교, 50장). A0끼리도 최대 절대 차이가 0이 아니면 이 기기에서 "차이 = 0" 기준을 쓸 수 없으므로 **멈추고 정민에게 보고**한다.
- 본 비교: 스레드 수마다 A1~A4 출력을 같은 스레드 수의 A0와 비교 (50장). **최대 절대 차이 = 0**이어야 한다.
- 0이 아니면 그 조합은 판정에서 빼고 차이를 기록한다 (정확도 재측정은 하지 않음).
- 3T vs 4T(A0끼리) 차이도 기록만 한다.

## 5. 판정 규칙 (사전 등록)
비율 = 같은 세션 안의 A0 대비, 3세션 중앙값.

| 판정 | 조건 (모두 만족) |
|---|---|
| **채택 (속도)** | ① G1 통과 ② **4T p50 ≤ −3%** ③ 1T·2T p50 **+2% 이내** ④ 4T p90 **+5% 이내** |
| **채택 (CPU 효율)** | ① G1 통과 ② 4T p50 **±2% 이내** ③ 1T·2T p50 +2% 이내 ④ **4T 장당 CPU ms ≤ −10%** (0.5초 꼬리 포함 값) |
| 효과 없음 | 위 둘 다 아님 |

- **1T 대조군 규칙**: 어느 세션에서든 1T에서 A0 대비 ±2%를 넘는 차이가 나오면 drift로 보고 **그 세션을 1회 다시 잰다** (원래 세션 값은 기록으로 남김). 다시 재도 같으면 그대로 판정하고 사실을 적는다.
- 여러 조합이 채택이면: 속도 채택 > CPU 효율 채택, 같은 종류 안에서는 4T p50이 가장 낮은 것. 차이가 1% 이내면 바꾸는 키가 적은 쪽.
- **3T는 판정에 쓰지 않는다.** 측정 규칙(1·2·4T)이 정해져 있기 때문이다. 단, "4T 예산에서 3스레드가 더 빠르다"면 보고서에 관찰로 적는다.
- **교차 확인 (필수, E12-3 계획서 5절)**: 258V에서 채택된 조합은 **다른 CPU 1대**에서 A0 vs 채택 조합만 다시 잰다(4T·1T, 3세션). 같은 방향(4T p50 ≤ 0%, 1T +2% 이내, CPU 효율 채택이면 CPU ms ≤ 0%)이 아니면 **제출 기본값에 넣지 않고** "258V에서만 효과"로 기록한다.
  - 교차 확인 PC 후보: 준혁 데스크톱(285K) 또는 i7-1165G7. 일정상 못 하면 기본값 변경 없음.
- 결과로 모델 파일은 바꾸지 않는다.
