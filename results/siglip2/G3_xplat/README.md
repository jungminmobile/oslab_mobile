**해석**
- **최종 모델은 x86 두 세대(AVX-512 VNNI, AVX-VNNI)에서 출력이 비트 단위로 같다** → 채점 PC가 VNNI가 있는 x86이면 보고서 수치가 그대로 재현된다.
- ARM에서는 S8·U8+rr 모두 출력이 조금 다르다(정수 커널 구현 차이). S8이 더 많이 다르다 (cos 차이 0.0072 vs 0.0040) — ARM은 S8 활성값을 U8로 바꾸지 않고 그대로 계산하기 때문으로 보인다(준용, 추정). 최종 U8+rr의 정확도 차이는 0.00 [−0.6, +0.5]로 없다.
- 아직 확인 못 한 것: VNNI가 **없는** x86 (reduce_range의 효과가 실제로 필요한 경우, D-030 ④).
