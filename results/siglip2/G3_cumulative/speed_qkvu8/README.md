- **10/14 17:31~18:19 측정(`../speed/README.md`)과 절대값이 크게 다르다.**
  - 4스레드 FP32: 148.0 → 211.1 ms (+43%)
  - 4스레드 S8: 151.7 → 188.8 ms (+24%)
  - 4스레드 U8: 77.0 → 106.8 ms (+39%)

  - 원인 가설: ① 발열·전원 상태로 CPU 클럭이 바뀌었고, AVX-512를 많이 쓰는 FP32 GEMM이 더 영향을 받음 ② 30초 확인으로 잡히지 않은 배경 부하 ③ 노트북 모드 변화 (쭈리 확인 요청)
  - **이 PC에서는 S8 대 FP32의 4스레드 순위가 측정마다 바뀐다.** PRD 속도 하한 판정은 이 PC의 비공식 값으로 내리지 않고, 정민 노트북의 공식 측정(D-010)으로 하는 것을 제안한다.
- 두 측정 모두에서 변하지 않은 것: **U8(=QKV U8)은 모든 스레드에서 FP32의 약 절반**이다 (−48~−57%).
