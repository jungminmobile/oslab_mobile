## 판정
- **H2 기각**: 정수 MatMul은 1→4스레드에 63.5→33.6 ms(1.9배)로, float MatMul(FP32 304→137 ms, 2.2배)과 비슷하게 빨라진다.
- **H1 채택**: S8의 Q/DQ 시간은 스레드를 늘려도 줄지 않고 오히려 늘었다 (44.3→61.9 ms). 4스레드에서 전체의 36%다.
- S8은 U8보다 DQ가 26번, Q가 13번 더 실행된다. 정수로 합쳐지지 않는 QKV 투영 12개와 헤드 kv 1개마다 활성값 DQ, **가중치 DQ**(매 추론마다 int8 가중치를 float로 되돌림), 출력 Q가 남는 것으로 보인다. 가중치 DQ가 주요 원인이라는 것은 추정이다 (노드별 시간은 원본 `profile.jsonl`의 `by_op_ms`에 연산 종류 합계만 있다).
- 프로파일링 자체의 오버헤드가 있어 절대 시간은 `bench_speed` 값과 다르다. 비교는 같은 조건 안의 비율로만 한다.
