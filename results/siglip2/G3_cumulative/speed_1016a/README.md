# 지연 2·3회째 측정 (10/16 03:32~04:30, `speed_1016a`·`speed_1016b`) — U8 + reduce_range 3회 측정 완성

**결론: ORT 최종(fc2L2 U8 + reduce_range)은 세 측정 모두, 모든 스레드에서 FP32의 약 절반이다 (4스레드 −49.6 / −48.7 / −49.5%, 중앙값 −49.5%). S8 fc2L2는 4스레드에서 +0.5 / −13.7 / −11.9%로 측정마다 흔들린다.** D-030 확정의 남은 확인(지연 3회)을 채웠다.

## 조건
- `siglip2/scripts/night_1016.sh` (커밋 `68cd06a`, 측정 부분은 `speed_1016.sh`와 같음). `s2_bench_speed.py --warmup 20 --n 200 --repeats 3`, 배치 1, 스레드 1·2·4, 모델 4개 번갈아.
- 잠금 안에서 전체 CPU 30초 평균 25% 미만일 때만 시작 (6번 모두 4%). 고성능 전원 모드(쭈리 확인), WSL 종료 뒤, 개인연구 세션은 폰 러너만.
- 이 PC(i7-1165G7) 값이라 **비공식**(D-010). 비교는 같은 측정 안의 FP32 대비 비율(평균 ms 기준).
