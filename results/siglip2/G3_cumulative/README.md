# G3 누적 구성: 보호하는 fc2 줄이기 — 크기·정확도 곡선 (2026-10-13, 진행 중)

출발점은 보정 방식 비교의 최선(`../G3_calib_method`): Percentile 99.999(비대칭, 16장씩 나눠 누적) + **MatMul만 INT8** + 블록 5~11 fc2 FP32.
여기서 FP32로 남기는 fc2를 줄여 크기를 더 줄인다. 잔차 흐름(Add·LayerNorm)과 GELU는 모든 구성에서 FP32.
스크리닝: dev 6종 각 앞 200장, **정수 커널**, 고화질 cos(주)·Δtop-1(참고) (D-024). 보정 highres 256장 시드 0. 이 PC.

**중간 결론: 블록 5와 9의 fc2 두 개만 FP32로 두면 충분하다 (fc2L2: 고화질 cos 0.956, Δtop-1 +0.3%p, 105.3 MiB = FP32 대비 −70.3%). 둘 중 하나라도 INT8이면 크게 떨어진다.**

## 실행 명령
```bash
cd siglip2
bash scripts/g3_cumulative.sh screen    # fc2L4, fc2L2 (커밋 63d455f)
bash scripts/g3_cumulative.sh screen2   # fc2L1(블록 5만 / 9만), fc2L2 U8 (커밋 6d2eede)
bash scripts/g3_cumulative.sh full      # 상위 후보 dev 전체 재측정 (진행 중)
bash scripts/g3_cumulative.sh speed     # 지연 (다른 작업이 없을 때)
```
