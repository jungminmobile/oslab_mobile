## 0. 원칙 (결과 전 고정)

- 모든 비교는 **dev**로 한다. 정확도는 정수 커널(ORT 1.25.0, ORT_ENABLE_ALL), 주 지표는 고화질 5종 평균 Δtop-1(FP32 대비)과 짝 부트스트랩 95% 구간(층화, 시드 0, 1000회). CIFAR A는 따로 적는다.
- **test는 후보를 고르는 데 쓰지 않는다.** B/32 test는 팀이 B/32를 제출 모델로 고른 뒤에만 1회 돌린다 (약 3시간, 밤). B/16 test는 이미 1회 썼다(D-044).
- B/32 모델: `hf-hub:timm/ViT-B-32-SigLIP2-256` (256×256, 패치 32 → 토큰 64개). 전처리는 open_clip 설정 그대로.
  B/32 산출물은 **별도 폴더** `D:\mokerton\artifacts\siglip2_b32`에 둔다 (`SIGLIP2_ARTIFACTS`로 지정, B/16 캐시 덮어쓰기 방지 — 폴더마다 `model_id.txt`로 확인).
- **B/32의 주 후보 레시피는 지금 고정한다:** B/16 최종(M2rot_ort)과 같은 방법 — rothad 회전 + M2 레지스터 캐시(준용 G6_pre 통일 규칙 `15@6:5, 7@10:9`, FP32 단계에서만 정한 값) + MatMul 전부 INT8, U8 + reduce_range, percentile 99.999, 보정 highres 256장 시드 0.
  나머지 B/32 실험(민감도 지도, 보정 방법, 혼합 정밀도 등)은 **같은 현상이 B/32에서도 나오는지 확인하는 재현**이다. 그중 어떤 구성이 주 후보보다 dev 전체에서 유의하게 좋으면(짝 차이 하한 > 0) "대안"으로 후보표에 함께 적고, 고르는 것은 팀이 한다.
- 실행 규칙: 무거운 작업은 공용 잠금(`heavy_lock.py --owner siglip2`), 지연은 고성능 모드·PC 조용할 때(job 이름에 "needs idle PC"), 이 PC 속도는 "비공식". 결과마다 커밋 해시·dirty·CPU 플래그·ORT 버전.

**A5 판정 (결과 전 고정, D-038 (나)와 같은 꼴):**
1. 스크리닝: 같은 세션 4스레드 지연이 M2rot_ort보다 **15% 이상 빠른** 구성만 다음 단계로 (프로파일링에서 정한 기준).
2. 그 구성은 dev 전체 짝 비교(M2rot_ort 대비 고화질 Δtop-1 95% 구간)와 지연 3세션 × 스레드 1·2·4로 다시 잰다.
3. **둘 다 만족**(구간이 0을 포함하거나 더 좋음 + 4스레드 3세션 중앙값 15% 이상 빠름)하면 "예선 모델 교체 후보"로 팀에 올린다. 바꾸면 test를 세 번째로 써야 하므로 채택은 팀이 정한다. 아니면 "시도했지만 넣지 않은 것"으로 기록.

**순서 (쭈리 10/20): B/16 개선(A1 → A5 → A2·A3·A4)을 먼저, 그다음 B/32.** 잠금이 비는 동안 B/32 단계를 끼워 넣지 않는다 (지금 돌던 B/32 dev 캐시 만들기만 끝까지).

## 4. 추가 (10/20 22시, 쭈리 "기다리는 동안 이 PC에서 해 볼 만한 것"): B/32 블록 0 보호 — 결과 전 고정

- 배경: B/32 민감도 지도에서 **블록 0을 INT8로 하면 무너진다** (cos 0.521, B/16은 0.928). 주 후보(M2rot, MatMul 전부 INT8)의 손실 −0.79%p 일부가 블록 0에서 올 수 있다.
- 구성 (주 후보와 같은 FP32·같은 양자화 옵션, `--exclude`로 FP32 유지만 다름):
  - X1 블록 0 fc2만 FP32 / X2 블록 0 fc1·fc2 / X3 블록 0 MatMul 전부(qkv·attention 2개·proj·fc1·fc2)
- 순서: dev 6×200 스크리닝(고화질 cos) → cos가 가장 높은 1개를 dev 전체 짝 비교(주 후보 대비) + 4스레드 지연(주 후보와 같은 실행, PC 조용할 때)
- **판정:** (1) 주 후보 대비 dev 전체 고화질 짝 차이 95% 구간 하한 > 0 **그리고** (2) 4스레드 지연 증가 ≤ 5% → "B/32 개선 후보"로 후보표에 추가 (채택은 팀). 아니면 기록만.
