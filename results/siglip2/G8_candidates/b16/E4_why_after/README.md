# E4: 회전·M2가 거대 활성값을 실제로 없앴는가 (계획, 2026-10-21 결과 전 고정)

- 계기: 보고서 v4 독립 검토 — "M2와 회전으로 0으로 반올림되는 손실이 사라졌다"는 문장의 직접 근거가 없음 (0으로 반올림되는 비율을 다시 재지 않음).
- 방법 (`siglip2/s2_why_after.py`): 2×2와 같은 FP32 그래프 4개(원래 / 회전만 / M2만 / 회전+M2, A1에서 이 PC가 만든 `onnx_g8`)의 MatMul 입력 활성값 79개를 dev 64장(Pets·Caltech 앞 32장씩, G3_why와 같은 사진)으로 잰다.
  - 텐서당 눈금 1개(MinMax, UINT8 비대칭, 64장 전체 범위)일 때 **0으로 반올림되는 원소 비율**, 사진마다 max|x|/mean|x|(쏠림)
- **판정 없음 (기록만)**. 보고서 6.6·5.3의 해당 문장을 결과대로 고친다. 예측(가설): 원래·회전만은 블록 5 이후 fc2 입력에서 비율이 높고, M2를 쓴 두 그래프에서 크게 낮아진다.
