# E5: 보정 사진 시드에 따른 흔들림 (계획, 2026-10-21 결과 전 고정)

- 목적: 최종 레시피(M2rot_ort)의 정확도가 보정 사진 뽑기(시드 0)에 운 좋게 걸린 값이 아닌지 확인 (보고서 6.2 타당성). RN50 트랙은 시드만 바꿔도 −0.64 ~ −1.26으로 흔들렸다(정민 E3).
- 방법: 준용 M2rot FP32(`16ef696e…`, Release)에서 이 PC로 양자화 옵션은 그대로 두고 **보정 시드만 0·1·2**로 바꿔 INT8 3개 → dev 전체(고화질 Δ·95% 구간·cos·CIFAR A). M2 캐시 상수는 배포 모델과 같은 시드 0 그대로.
- 주의: 보정 후보 풀이 311장이고 그중 256장을 뽑으므로 시드끼리 사진이 많이 겹친다 (흔들림의 하한).
- **판정 없음 (기록만)**: 세 시드의 Δ 범위·평균을 보고서에 적는다. 결과와 상관없이 제출 파일(e84c3727…)은 바꾸지 않는다.
