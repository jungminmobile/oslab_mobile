## 3. 한계 절에 넣을 내용 (③ 초안 기반, 실험 결과에 따라 고침)

1. VNNI 없는 x86·ARM에서 제출 파일 미확인 (ARM은 R0만 98.1% 일치).
2. Hailo −0.41은 구성 선택에 쓴 dev 값, 이전 HEF.
3. M2는 sink 위치가 고정된 모델에서만 (SigLIP 1세대 불가). 위치·시작 블록은 모델·해상도마다 다시 정함.
4. B/32 통일 규칙은 첫 규칙 실패 뒤 고친 것 (판정은 따로 뗀 확인 세트). B/16 제출 모델은 이전 규칙.
5. M2 상수·보정 사진은 시드 0, 평가와 같은 5개 분포의 train. 분포 다른 입력(CIFAR −4.09, ImageNetV2 −0.69)에서 손실이 더 큼.
6. 빌드 5개 dev −0.23~−0.49, test −0.34는 유의한 손실 → "약 0.2~0.5%p 손실".
7. SNR 최솟값 관찰은 그래프 4개·결과 뒤 분석·시뮬레이션.
8. 지연은 노트북 1대 비공식, 날마다 절대값 최대 70% 차이(148~252), 개선율도 수 %p 흔들림. 메모리는 측정 방식에 따라 −52~−65%.
9. test 2회 사용 순서 (R0 test 뒤 탐색, 교체는 test 전 dev로 확정, 사후 변경 3건 D-044).
10. Caltech dev 95.0 vs test 84.7 분포 차이.
