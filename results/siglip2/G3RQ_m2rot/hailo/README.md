## 3. 판정 규칙
- 정확도: 구간 **하한 > 0 → "M2rot이 유의하게 좋음"**, **0을 포함 → "동률"**, **상한 < 0 → "나쁨"**.
- 지연: 3세션 중앙값으로 rothad 대비 증가율 (B/A − 1).
- 제안:
  - "유의하게 좋음" + 지연 증가 ≤ 10% → **Hailo 최종 교체를 팀에 제안**.
  - "유의하게 좋음" + 지연 증가 > 10% → 정확도·지연 트레이드오프 표로 **팀이 결정**.
  - "동률" 또는 "나쁨" → **rothad 유지**.
- 채택은 팀 결정 (siglip2/CLAUDE.md).
