# SigLIP2 후보표 (팀 선택용, 2026-10-14 초안)

이 표는 **선택을 돕는 자료**다. 최종 트레이드오프 지점(정확도·속도·용량)은 Claude가 정하지 않고 팀이 상의해서 고른다 (CLAUDE.md).
모든 정확도는 정수 커널(ORT) 또는 DFC 양자화 에뮬레이터 값이다. 이 PC 지연은 **비공식**이다 (D-010).

## 3. 팀이 정할 것

1. **S-B(ORT 최종)**: fc2L7 / L4 / L2 / L2 U8 중 하나. S8 세 개는 정확도 동률이지만 4스레드에서 속도 하한을 통과하지 못한다. U8은 속도 하한을 통과하고 지연이 절반이지만 정확도가 −0.91%p(S8보다 −0.41%p 유의)다.
2. **S8 vs U8 (D-023 재검토)**: 정확도(S8 우세, 0.41%p) 대 지연(U8 약 2배 빠름, S8은 4스레드 속도 하한 실패). PRD 속도 하한을 지키려면 U8이 필요해 보인다. 또는 S8에서 attention 행렬곱도 정수로 돌게 하는 방법(예: attention MatMul만 U8)을 새 옵션으로 실험해 볼 수 있다 (팀 결정).
3. **S-D(DFC 최종 `.alls`)**: C 또는 D. 정민 노트북 교차 확인(D-027) 시점.
4. DFC 스크리닝 dirty 오표시 3행을 다시 돌릴지.
5. 원인 분석(`../G3_why`)을 보고서의 "CNN vs Transformer" 서사에 어떻게 쓸지.
