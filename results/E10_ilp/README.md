## 가법성 (PREREG 2절)
- 구성별 예측 4T vs 실측 4T 차이: 1.7~8.1% (모두 10% 안 → "위반" 아님).
- 그러나 **B2 자체는 예측 27.32 ms vs 실측 23.26 ms (17% 차이)**, 단위를 더한 cos 예측은 B2를 오히려 나쁘게 본다(stem.c2 −0.073, L1.0 음수). 민감도는 stem·L1.0에서 강하게 비가법적이다(같이 FP32로 둬야 좋아짐).

## 왜 졌나 (실패 기록)
1. **민감도가 더해지지 않는다**: stem.c2나 L1.0을 하나만 FP32로 두면 ORT 정수 커널 경계 문제로 나빠지고, 묶어서 둬야 좋아진다(E4-B B1, E4-D와 같은 현상). 단위별 합을 쓰는 정수계획은 B2 같은 "묶음 해"를 찾지 못한다.
2. **단위별 지연(0.5~3 ms)이 노트북 측정 잡음(±2~3 ms)과 비슷하다**: 3회 중앙값에서도 일부 블록 t_u가 0 아래 → DP가 "공짜"로 보고 L2.3·L3.1·L3.5 같은 큰 블록을 FP32로 골랐고, 실제로는 크기 +13 MiB·지연 증가.
3. **B2가 이미 비용이 싼 곳(stem·L1.0은 연산·가중치가 작음)만 FP32로 둔다**: 그래서 탐욕법의 "비용 무시" 한계가 RN50에서는 실제 손해로 나타나지 않았다.
