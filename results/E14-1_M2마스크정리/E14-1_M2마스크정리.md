## 1. 왜 하는가

- O 그래프의 `Sub` **27개 전부**가 M2 마스크다. 원소별 작은 연산이라 4T에서 오히려 느리다(E12-3: Sub 1T 0.47 ms → 4T 0.66 ms).
- 이 연산들은 **양자화되지 않는 float 구간**에 있다 → Q/DQ 값이 하나도 안 바뀐다 → 재양자화·보정 캐시 없이 **O와 바로 비교**할 수 있다.
- 이 실험만으로 제출 모델을 바꾸지 않는다. 채택 후보여도 **팀 결정 D-050** 뒤에 E14 결과를 모아 한 번에 정한다.

## 2. 바꿀 곳 (그래프 직접 확인, 10/23)

| 종류 | 개수 | 패턴 | 하는 일 |
|---|---|---|---|
| K·V sink | 20 | `Sub(kc_b*/vc_b*, Squeeze 출력)` → `Mul(m)` → `Add` | attention sink 자리 K·V를 상수로 |
| MLP 입력 sink | 7 | `Sub(uc_b*, norm2 출력)` → `Mul(m)` → `Add` | 블록 5~11 sink 자리 u_c를 상수로 |
| **합계** | **27** | 단순 21개 (Add가 X를 바로 받음) + 비단순 6개 (Add 입력이 다른 경로) | |

- 마스크 `m` 6종(`trunk.m_b6_0`, `trunk.m_b10_1`, `trunk.zm_b5`, `trunk.zm_b9`, 상수 Transpose 2개)은 **값이 0과 1뿐**이다.

## 3. 바꾸는 방식

| ID | 식 | 노드 (1곳) | 줄어드는 노드 (27곳) | 기대 4T (오버헤드 보정 추정) |
|---|---|---|---|---|
| O (기준) | `X + m·(c − X)` | Sub·Mul·Add 3개 | — | 16.3 ms |
| **W1** | `X·(1−m) + (m·c)` — `(1−m)`, `m·c`는 미리 계산한 상수 | Mul·Add 2개 | 27개 | 약 −0.36 ms (−2.2%) |
| **W2** | `Where(mask_bool, c, X)` | Where 1개 | 54개 | 약 −0.7 ms (−4%) |

**기대치 근거**: E12-3의 Sub 0.66 ms에는 프로파일 오버헤드(노드당 약 11.1 µs × 27 ≈ 0.30 ms)가 들어 있다. 이를 빼면 Sub 실제 시간은 약 0.36 ms다.

**수치가 어떻게 되나**
- m이 0/1이라 W1·W2 모두 sink 자리는 정확히 `c`, 나머지 자리는 정확히 `X`가 된다.
- 원래 식 `X + 1·(c − X)`는 반올림 때문에 sink 자리에서 `c`와 1 ulp 다를 수 있다 → **O와 W는 비트 단위로 같지 않을 수 있다.**
- 반면 **W1과 W2는 서로 비트 단위로 같아야 한다** (X = −0일 때 W1 +0, W2 −0 차이만 허용). → G2(b)로 검사.

**바꾸는 규칙**
1. **비단순 6개**: Add 입력이 Sub 입력과 **같은 텐서(같은 이름)**이거나, 형태 연산만 거쳐 값이 같다는 것을 2장 실행으로 확인(max|Δ| = 0)한 경우에만 바꾼다. 아니면(식이 `X′ + m(c − X)`라 선택이 아님) 그대로 두고 개수·이유를 기록한다.
2. **마스크 상수**: `(1−m)`, `m·c`, `mask_bool`은 상수 Transpose 2개를 **적용한 뒤의 값**으로 미리 계산해 initializer로 넣는다. 새 initializer 크기 합을 기록한다(`m·c`는 브로드캐스트로 커질 수 있음).
3. **범위**: 위 27곳만. Q/DQ 노드와 그 상수, 다른 연산은 건드리지 않는다.

## 6. 판정 규칙 (사전 등록)

비율 = 같은 세션 안의 O 대비, 3세션 중앙값.

| 판정 | 조건 |
|---|---|
| **채택 후보** | 아래 ①~⑤ 모두 만족 |
| 효과 없음 | ②만 불만족 (4T 감소가 1.5% 미만) |
| 기각 | ④ 또는 ⑤ 불만족 |

| # | 조건 |
|---|---|
| ① | G0~G2 통과 |
| ② | **4T p50 ≤ −1.5%** |
| ③ | 1T·2T p50 **+2% 이내** |
| ④ | 정확도: G2b에서 top-1 모두 같음, 또는 dev 전체 고화질 **O 대비 95% CI 하한 > −0.3%p** |
| ⑤ | peak 메모리 **+2% 이내** |

**고르는 법**
- 둘 다 채택 후보 → 4T p50이 낮은 쪽. 차이 1% 이내면 노드 수가 적은 W2.
- 하나만 채택 후보 → 그쪽.
- **E14-2(GELU 융합)는 채택된 쪽 위에 쌓는다.** 효과 없음이면 O 위에서 한다.

**사전 기록**
- 기준 −1.5%는 기대치(−2~4%)에 맞춰 E12·E14-2의 −3%보다 낮게 잡았다. 세션 간 잡음(0.6% 이내)보다는 크다.
- W1 기대치(−2.2%)는 기준과 0.7%p 차이라 잡음에 가깝다. **W1이 "효과 없음"이어도 예상 범위**로 해석한다. 기준은 바꾸지 않는다.
