## D-001 트랙 분담
- 상태: 확정 / 2026-10-07 / 쭈리
- 결정: RN50(CNN) 트랙은 정민이 계속, SigLIP2(Transformer) 트랙은 쭈리. 같은 조건으로 재서 CNN vs Transformer 비교를 만든다.
- 대안: RN50 단일 트랙에 합류 / ViT-B/32 트랙
- 근거: RN50 트랙은 FP32 기준치·민감도 지도·균형점(c3/c4)까지 진행됨(노션 10/7 재측정). 자유주제는 모델·벤치마크 선정 사유와 실험 설계가 채점 대상이라 아키텍처 비교가 설계 점수에 유리.
- 틀렸다면 보일 신호: G1에서 SigLIP2가 Hailo-10H에 올라가지 않음 → D-003 경로
- 영향: 공통 코드는 RN50 트랙 것을 import, 수정은 PR로

## D-002 메인 모델과 해상도
- 상태: 제안 (G1 게이트 통과 시 확정) / 2026-10-07
- 결정: `timm/ViT-B-16-SigLIP2`, 224 고정 해상도. NaFlex 변형 제외.
- 대안: 256·384 해상도 변형, ViT-B/16 CLIP
- 근거: 패치 수가 가장 적어 NPU 부담이 작고, 고정 입력이라 컴파일에 적합. NaFlex는 입력 크기가 가변.
- 틀렸다면 보일 신호: 224에서 컨텍스트 수가 과도하게 많거나 정확도가 공개 보고치와 크게 다름

## D-003 대체 경로
- 상태: 제안 / 2026-10-07
- 결정: G1에서 블록 내부 연산이 컴파일되지 않으면 ViT-B/32로 전환. pooling head만 실패하면 head를 호스트에서 실행.
- 근거: ViT-B/32는 Hailo-10H 공식 HEF와 실칩 동작이 연구실에서 확인된 Transformer

## D-004 최적화 범위
- 상태: 확정 (RN50 트랙과 동일) / 2026-10-07
- 결정: 이미지 인코더만 양자화. 텍스트 분류기는 FP32로 한 번 계산해 캐시.
- 근거: zero-shot 분류의 런타임 경로에 텍스트 인코더가 없음. RN50 트랙과 같은 범위여야 비교가 성립.
- 영향: 보고서에 범위와 근거를 명시해야 "모델 크기 감소"가 오해되지 않음

## D-005 보고 정확도는 정수 커널
- 상태: 확정 (팀 합의) / 날짜는 첫 세션에서 기입
- 결정: 보고 정확도는 정수 커널만. fake-quant는 선택 옵션으로 남겨 많은 구성의 1차 스크리닝에 쓰고, 상위 5개는 정수 커널로 재측정.
- 근거: 학술부가 제출 모델을 직접 실행해 재현 검증. 정수 커널 결과는 CPU에 따라 달라질 수 있어(팀원 관찰), 스크리닝은 결과가 일정한 fake-quant로 하는 것이 효율적.
- 추가 조건: 순위 상관 기록. CPU 플래그 기록. U8S8 구성은 VNNI 없는 x86에서 포화 가능성이 있으므로 G6에서 reduce_range 또는 S8S8 대안과 비교.
- 틀렸다면 보일 신호: fake-quant 순위와 정수 커널 순위가 크게 어긋남 → 스크리닝 범위를 넓혀 재측정
