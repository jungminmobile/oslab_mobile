## 4. PRD 요약과 원문의 차이 (확인 필요)

1. **"속도 하한(모든 스레드 수에서 FP32보다 느리면 제외)"과 "추론 시간이 비정상적으로 느리면 안 된다"는 원문에 없다.** 원문 4.4는 "Baseline 대비 추론 속도 … 감소 정도"를 점수로 볼 뿐이다. 다른 공지(Q&A 등)에서 왔는지 정민에게 확인. 출처가 없으면 대회 규칙이 아니라 **팀 규칙**이다.
2. **"채점자는 ORT 기본 설정으로 실행"(PRD R5 근거)도 원문에 없다.** 원문은 우리가 낸 스크립트로 재현한다고 읽힌다 (4.2 "벤치마크 측정 및 추론을 실행할 수 있는 스크립트", 4.3). 정수 커널만 쓰는 팀 규칙은 그대로 두되, 세션 옵션 사용 가능 여부는 학술부 문의 대상.
3. **채점 PC 사양은 원문에 없다.** x86(VNNI 유무)·ARM 맥 모두 가능 → README에 측정 CPU·예상 범위를 적고, 가능하면 두 플랫폼 수치를 함께 싣는다 (PRD 위험 표와 같음).
4. **팀이 모델을 몇 개 낼 수 있는지 원문에 없다.** "대상 모델 및 선정 사유", "최적화 모델: … 최종 모델 파일"로 단수형이다. → **10/15 학술부 답: 모델 하나. CNN vs Transformer 비교로 보고서를 쓰면 탈락** (D-034). 팀은 RN50·SigLIP2를 따로 최적화하고 더 좋은 쪽을 낸다.
5. 저장소 `jungminmobile/oslab_mobile`은 **private**이다. 제출 시 학술부 접근 권한(초대 또는 공개 저장소·드라이브 링크)을 준비해야 한다.

## 5. 본선 참고 (원문 5절)

### 5-0. 본선 모델은 예선 모델을 이어서 쓴다 (10/20 원문 재확인)
- 2절·5.2: 본선은 **"예선에서 최적화한 커스텀 모델"**을 Hailo 툴체인으로 컴파일해 탑재·검증한다
- 5.2: **예선 벤치마크·측정 방법을 그대로** 적용해 서버와 엣지 결과를 비교한다 → 주 지연 지표는 예선과 같은 배치 1 (배치 처리량은 참고로만)
- 5.3: 최종 보고서에 **"예선 대비 변경 사항"**을 적는다 → Hailo 컴파일 과정의 조정(혼합 정밀도 배치, `resources_param`·`bucket` 등)은 허용되지만 기록·설명해야 한다
- 따라서: 예선 ONNX(M2rot_ort)와 본선 HEF(M2rot_D256L1)가 같은 그래프인 지금 구성(D-044)이 규칙에 잘 맞는다. **본선에서만 다른 모델(예: B/32)로 바꾸는 것은 규칙 위반 소지가 크다** — 필요하면 학술부에 먼저 묻는다. 변경 허용 범위는 원문에 명시돼 있지 않다
- (10/23 갱신) D-048로 **예선·본선 모두 B/32**. 예선 ONNX(O-AB, 바탕 FP32 `23236123…`, 배치 가변)와 본선 HEF(바탕 FP32 `a0eb502b…`, 배치 1)는 같은 PyTorch 모델(회전 행렬 `3a6391a2`, sink 규칙 `15@6:5, 7@10:9`, 같은 M2 상수)에서 export한 파일이다. O-A·O-B는 ORT 전용 변경이라 HEF에는 없음 → 최종 보고서 "예선 대비 변경 사항"에 기록

- 지급: Raspberry Pi 5 (8GB) + AI HAT+ 2 (Hailo-10H, 40 TOPS INT4 / 20 TOPS INT8, 온보드 LPDDR4X 8GB, PCIe Gen3)
- 본선 배점: 실기기 구동 완성도 30, 실측 성능(FPS·Latency·메모리) 30, 정확도 20, 발표·시연 20
- 예선과 **같은 벤치마크·측정 방법**으로 서버 vs 엣지 비교 → 지금 프로토콜을 본선까지 유지
- 제출: 최종 보고서(11/30 23:59), 발표 자료, `.hef` + 변환 스크립트·설정, 실기기 재현 코드

## 7. 학술부 답 (10/21, 쭈리 전달)
- **성능(속도·메모리·크기)은 절대 수치가 아니라 원본(Baseline) 모델 대비 개선율로 본다.** 팀 간 절대값 비교는 하지 않는다 → 처음에는 예선 제출 B/16 유지(D-046)의 근거로 썼다. 10/22 D-048로 B/32로 바꿈: 예선 개선율은 두 모델이 비슷하고, 본선에서 B/32만 Hailo Zoo 공개 HEF와 직접 비교되기 때문
